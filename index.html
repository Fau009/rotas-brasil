      Anima os veículos ao longo do trajeto usando o quadro de horários (GTFS). É uma simulação, não é a posição real.

      Como funciona

      Site estático no GitHub Pages. Uma automação (GitHub Actions) baixa os dados abertos periodicamente e publica em JSON. O botão Recarregar busca a versão mais recente já publicada.

      Fontes de dados

        Itinerários e horários: feeds GTFS via Mobility Database. Cidades: contornos municipais do IBGE. Mapa: © OpenStreetMap (detalhado) e Esri (claro/escuro). Estações sob demanda: Overpass API.
